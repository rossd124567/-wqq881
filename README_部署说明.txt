群组记账助手 · 客户独立版

本版无会员、无充值、无品牌宣传。

更新内容：
1. 必须回复指定群成员的消息发送 +300、-300、+300/8.2、-300/8.2 才会记账；供方是被回复者，入方是操作人。
2. 未回复直接发送正负记账指令，机器人回复：麻烦回复对应的正确入款码加账；不生成待确认订单，也不记账。
3. 发送 1 不再触发供方认领。
4. 负数冲减对应供方成绩，按实际金额及原输入汇率统计。
5. 今日入款及已下发按本账期统计，累计未下发按该群所有有效历史入款减所有有效历史下发计算，日切不会清零。
6. 普通算式自动回复「🧮 计算器」，不会写入账本。
7. 多群独立账本、撤销、清空、汇率、日切、Z0、操作人功能保留。

Railway 配置：
- BOT_TOKEN：新机器人的 Token
- ACCOUNTING_DB：/data/accounting.sqlite3（必须先挂载 /data 持久卷）
- 启动命令：python accounting_bot.py

部署前请备份 GitHub 文件与 Railway 数据库。保留现有存储卷，不要新建空数据库覆盖旧账本。
注意：这份代码已通过语法检查，尚未在 Telegram 线上实测。
