3. 多笔待确认时，供方必须回复对应确认提示发送 1。
4. 负数更正、下发、汇率、日切、撤销、清空、多群独立账本等原功能保留。
5. 已移除会员、充值、授权功能。
6. Railway 设置 BOT_TOKEN 为新机器人的令牌；启动命令 python accounting_bot.py。
7. 数据库建议使用持久卷并设置 ACCOUNTING_DB=/data/accounting.sqlite3。
